# AI Prompts Used

I used AI mainly to understand and improve the CSS of the Prodesk IT landing page. I also used it for a few small HTML and JavaScript doubts.

## CSS Prompts

### 1. CSS Layout

> I have created a landing page for Prodesk IT using HTML and CSS. Help me arrange the navbar, hero section and other sections properly using CSS Flexbox and Grid. Keep the CSS simple and beginner-friendly.

### 2. Responsive Design

> Help me make this landing page responsive for desktop, tablet and mobile screens using CSS media queries. Do not use Bootstrap or Tailwind.

### 3. Navbar Styling

> How can I create a clean and professional sticky navbar using normal CSS? The logo should be on the left and navigation links should be on the right.

### 4. Mobile Navbar

> How can I style a navigation menu for mobile screens using CSS so that it can be shown as a vertical menu when the hamburger button is clicked?

### 5. Hero Section

> Suggest simple CSS improvements for my hero section so it looks more professional. Use proper spacing, font sizes, alignment and a simple background.

### 6. Service Cards

> Help me create three responsive service cards using CSS Grid. Add a simple hover effect that makes the card move slightly upward and show a shadow.

### 7. Dark Mode CSS

> I am using JavaScript to add a `dark` class to the body. Help me write CSS for dark mode so that the background, text, navbar and service cards look good.

### 8. Glassmorphism

> How can I add a simple glassmorphism effect to my sticky navbar using CSS backdrop-filter? Keep it suitable for a professional website.

### 9. CSS Debugging

> Review my CSS and help me identify problems with spacing, responsiveness, alignment and mobile layout. Suggest simple fixes without changing the complete structure.


## Small HTML / JavaScript Assistance

### HTML

> Explain how I should structure a simple landing page using semantic HTML elements such as header, nav, section and footer.

### JavaScript

> Explain how to create a simple hamburger menu using vanilla JavaScript by adding and removing an active class from the navigation menu.

### JavaScript

> Explain how to toggle dark and light mode using JavaScript by adding and removing a `dark` class from the body.
