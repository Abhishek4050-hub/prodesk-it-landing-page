# Prodesk IT - Corporate Landing Page

A responsive landing page created for the Prodesk IT Sprint 01 assignment.

##Live Website

https://prodesk-it-landing-page-delta.vercel.app/

## Features

* Responsive navigation bar
* Mobile hamburger menu
* Hero section
* About section
* Services section
* Contact section
* Responsive footer
* Dark and light mode
* Hover effects
* Sticky navigation
* Glass effect on navbar
* Responsive design using CSS Grid and Flexbox

## Technologies Used

* HTML5
* CSS3
* JavaScript

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a browser.

No framework or package installation is required.
